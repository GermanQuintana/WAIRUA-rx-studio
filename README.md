# WAIRUA RX Studio

Prototipo de visor y medición radiográfica veterinaria con procesamiento local en el navegador.

**Estado:** versión experimental en desarrollo, pendiente de validación clínica. El soporte DICOM y las mediciones tienen limitaciones.

Para ejecutarlo, sirve los archivos estáticos con un servidor HTTP. Para publicar en GitHub Pages, selecciona la rama `main` y la carpeta `/ (root)` en Settings → Pages.
